# 🟨 Exemplos de JavaScript

Arquivos com exemplos práticos dos fundamentos de JavaScript, um tema por arquivo.

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

## Conteúdo

- Arrow functions, funções e expressões de função
- Parâmetros de funções
- Comparações e operador ternário
- Conversões de tipos, números e strings
- Template strings
- Truthy e falsy, booleanos
- Tratamento de erros
- Uso do `console`

## Como rodar

Com o [Node.js](https://nodejs.org/) instalado, rode qualquer arquivo:

```bash
node funcoes.js
```
